### Änderungen auf der Cloud

Durch das Update mussten auch einige bestehende Funktionen der Cloud angepasst werden.

_Die konkreten Änderungen auf der Cloud werden hier ergänzt, sobald sie feststehen._

{% hint style="warning" %}
Bei einem Versionsupgrade kann es vorkommen, dass etwas nicht sofort wie gewohnt funktioniert.

Fehler können wie gewohnt im Bereich [#fehlermeldungen](https://discord.com/channels/325017098592059392/1283079587080966297) auf dem Discord gemeldet werden.
{% endhint %}
