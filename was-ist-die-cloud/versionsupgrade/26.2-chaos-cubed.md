# 26.2 - Chaos Cubed

<figure class="wiki-illus"><img src="/img/wiki-illus/banner-26-2.webp" alt="Neue Inhalte aus Minecraft 26.2: Schwefel, Zinnober, Kupfergolem, Glücklicher Ghast und Nautilus"><figcaption>Schwefel, Zinnober, Kupfer, neue Mobs: Das bringt Minecraft 26.2 mit auf die Cloud.</figcaption></figure>

{% hint style="danger" %}
**Noch kein Termin.** Für das Versionsupgrade auf die 26.2 gibt es aktuell kein Datum. Alles auf dieser Seite ist eine Vorabinformation und kann sich bis zum Upgrade noch ändern.
{% endhint %}

Die Cloud läuft aktuell auf Minecraft **1.21.4** und wird mit dem nächsten Versionsupgrade auf **Minecraft 26.2 („Chaos Cubed“)** aktualisiert. Mit der neuen Version kommen neue Blöcke, Items und Mobs ins Spiel. Gleichzeitig werden bestehende Funktionen der Cloud angepasst, damit alles auch mit der neuen Minecraft-Version funktioniert.

## Das Wichtigste in Kürze

* **Was passiert?** Die Cloud wechselt von Minecraft 1.21.4 auf Minecraft 26.2.
* **Wann?** Der Termin steht noch nicht fest. Sobald er feststeht, findest du ihn hier und auf dem [Discord](https://discord.com/invite/abge).
* **Was musst du tun?** Die Cloud läuft immer auf der aktuellen Minecraft-Version. Nach dem Upgrade brauchst du also einen Client mit Version 26.2, um zu joinen. Wie du die Version im Launcher auswählst, steht unter [Server verbinden](../../auf-den-server-joinen/README.md).
* **Was ist neu?** Eine Übersicht über die neuen Inhalte findest du weiter unten.

## Neue Inhalte

Minecraft 26.2 bringt viele neue Inhalte, die auch auf der Cloud interessant sind.

{% hint style="info" %}
Nicht alle Neuerungen von Minecraft sind automatisch auf GrieferGames verfügbar. Einige Inhalte können aufgrund der technischen Umsetzung des Netzwerks angepasst, eingeschränkt oder deaktiviert sein. Was auf der Cloud grundsätzlich anders funktioniert als im normalen Minecraft, findest du unter [Mechanik-Änderungen](../../funktionen/mechanik-aenderungen/README.md).
{% endhint %}

## Was sich auf der Cloud ändert

Damit die Cloud mit der neuen Version läuft, müssen einige bestehende Funktionen angepasst werden. Welche das genau sind, steht noch nicht fest.

_Die konkreten Änderungen werden hier ergänzt, sobald sie feststehen. Schau vor dem Upgrade noch einmal auf dieser Seite vorbei._

## Nach dem Upgrade

{% hint style="warning" %}
Bei einem Versionsupgrade kann es vorkommen, dass etwas nicht sofort wie gewohnt funktioniert. Das ist normal und wird nach und nach behoben.
{% endhint %}

Wenn dir ein Fehler auffällt, melde ihn im Bereich [#fehlermeldungen](https://discord.com/channels/325017098592059392/1283079587080966297) auf unserem Discord. Wie eine gute Fehlermeldung aussieht, steht unter [Fehlermeldungen](../../allgemein/fehlermeldungen.md).
