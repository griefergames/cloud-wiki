# 26.2

{% hint style="danger" %}
Aktuell gibt es noch kein Datum für das kommende Versionsupgrade auf die 26.2.\
Alle folgenden Inhalte sind daher lediglich eine Vorabinformation.
{% endhint %}

Mit dem Versionsupgrade auf Minecraft **26.2** kommen einige neue Inhalte ins Spiel. Gleichzeitig wurden bestehende Funktionen der Cloud angepasst, damit alles auch mit der neuen Minecraft-Version funktioniert.

### Neue Inhalte

Mit Minecraft 26.2 gibt es einige neue Inhalte, die auch auf der Cloud interessant sind.\
Dazu gehören unter anderem:

* Neue Änderung 1
* Neue Änderung 2

{% hint style="info" %}
Nicht alle Neuerungen von Minecraft sind automatisch auf GrieferGames verfügbar. Einige Inhalte können aufgrund der technischen Umsetzung des Netzwerks angepasst, eingeschränkt oder deaktiviert sein.
{% endhint %}

### Änderungen auf der Cloud

Durch das Update mussten auch einige bestehende Funktionen der Cloud angepasst werden.\
In diesem Upgrade hat sich folgendes geändert:

* Neue Änderung 1
* Neue Änderung 2

{% hint style="warning" %}
Bei einem Versionsupgrade kann es vorkommen, dass etwas nicht sofort wie gewohnt funktioniert.\
Fehler können wir gewohnt im Bereich [#fehlermeldungen](https://discord.com/channels/325017098592059392/1283079587080966297) auf dem Discord gemeldet werden.
{% endhint %}
