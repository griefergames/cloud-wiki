# Schneeballschlacht

## Spawn-Punkte

Es werden mehrere [Spawnpunkte](./#spender-dropper) benötigt, welche immer zufällig in der Runde für den Spawn und Respawn genutzt werden. Zusätzlich wird ein [Pre-Spawn](./#werfer-dispenser) benötigt.

## Schnee-Platten

Um im Spiel an weitere Schneebälle zu kommen, werden auf der Karte Schneeplatten (-teppiche) benötigt. Diese können auch in verschiedenen Höhen platziert werden, jedoch dürfen sie keinen vollen Block ergeben (8 Schichten).
