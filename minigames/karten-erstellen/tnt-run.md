# TNT-Run

Bei den Karten für TNT-Run kommt es vor Allem auf einen Block an: <img src="../../.gitbook/assets/image (40).png" alt="" data-size="line"> <mark style="color:red;">**TNT**</mark>

## Spawn-Punkte

Für eine TNT-Run Map wird nur ein [Spawn-Punkt](./#spender-dropper) benötigt. Die Spieler starten gemeinsam an einem Spawn-Punkt und werden nicht verteilt.

## Die TNT-Schichten

<figure><img src="../../.gitbook/assets/image (1).png" alt="" width="375"><figcaption><p>TNT-Schicht</p></figcaption></figure>

Die verschiedenen Ebenen werden anhand der platzierten TNT-Blöcke erkannt. Es wird mindestens eine TNT-Ebene benötigt, nach oben sind keine Grenzen gesetzt.

{% hint style="info" %}
Das System bildet aus jeder Y-Schicht, in der sich ein TNT-Block befindet einen Layer. Werden z.B. Treppen o.ä. aus TNT verbaut, wird für jede Stufe ein Layer erkannt.&#x20;
{% endhint %}

Eine TNT-Schicht besteht unten immer aus TNT. Der Block über dem TNT ist frei wählbar und muss nicht aus Sand o.ä. bestehen. Hier sind auch Muster aus verschiedenen Blöcken möglich. Es ist ebenfalls erlaubt halbe Blöcke, wie Stufen, zu verwenden. Es sollte jedoch darauf geachtet werden unter dem Spawn-Punkt einen vollen Block zu verbauen.
