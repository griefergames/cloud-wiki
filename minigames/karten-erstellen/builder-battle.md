# Builder Battle

Das Ziel des Spiels ist es, dass die anderen Spieler möglichst schnell das Bauwerkt erraten.

### **Spawn-Punkte** <a href="#_hbw6285ps3ye" id="_hbw6285ps3ye"></a>

Für eine Builder Battle Map wird nur ein Spawn-Punkt benötigt. Pre-Spawn-Punkte werden nicht benötigt.

{% hint style="info" %}
Für Builder Battle muss eine Spielfläche gebaut werden. Beim Generieren der Map wird diese dann für 10 Spieler kopiert.
{% endhint %}

### **Die Spielfläche** <a href="#_saesnaj1w8mq" id="_saesnaj1w8mq"></a>

<figure><img src="../../.gitbook/assets/image (40).png" alt=""><figcaption><p>Übersicht der Builder Battle Spielfläche</p></figcaption></figure>

Die Spielfläche wird durch zwei <img src="../../.gitbook/assets/image (8) (2).png" alt="" data-size="line"> **Redstoneblöcke** markiert. Diese geben den Bereich an, indem der Spieler bauen kann.

{% hint style="warning" %}
Achtung: Eure Map sollte eine Decke haben und abgeschlossen sein, da die Spieler sonst ihre Gegner besuchen können, um die Wörter vorab zu erkunden.
{% endhint %}
