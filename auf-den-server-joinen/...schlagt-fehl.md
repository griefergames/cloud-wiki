# ...schlägt fehl

### Unterstützte Versionen

Wir unterstützen das Verbinden mit Minecraft-Clients in den Versionen **ab 1.21.4**. Für ein fehlerfreies Spielen empfehlen wir, die **aktuelle Version des Cloud-Netzwerks** zu verwenden.

{% hint style="info" %}
Die aktuelle Version des Cloud-Netzwerks ist die **1.21.4**.
{% endhint %}

Die Minecraft-Version kann im Launcher der Java-Edition wie folgt geändert werden:

1. Minecraft Launcher starten
2. "Installationen" auswählen
3. "Neu" auswählen
4. Name vergeben
5. Spielversion auswählen (siehe oben)
6. Button "Speichern" drücken
7. "Spielen" auswählen
8. Dropdown-Box in der unteren linken Ecke öffnen und das angelegte Profil anklicken
9. Button "Spielen" drücken

Neue Spielversionen werden von uns schnellstmöglich nach Release durch Microsoft freigegeben. Dies kann unter Umständen einige Stunden bis Tage dauern. Den aktuellen Stand zu Updates erfahrt ihr auf unserem [Discord-Server](https://discord.gg/abge).

{% hint style="warning" %}
Beta-Versionen der Bedrock Edition und Entwicklungs-Versionen der Java Edition werden von uns **nicht** unterstützt.
{% endhint %}

### Serververbindung schlägt fehl

Sollte eine Verbindung über die Hauptadressen nicht möglich sein, kann im Einzelfall die Nutzung der alternativen Adresse `alt.griefergames.net` sinnvoll sein.

### Zu viele Verbindungen

Spielen viele Leute gleichzeitig bei euch über ein Netzwerk _(z. B. Familie, Schule, Wohnheim)_? Aus Sicherheitsgründen limitieren wir die Anzahl an Verbindungen pro IP-Adresse. Betroffene Nutzer können mit einem VPN einen anderen Access-Server auswählen.

### Modifikationen

Einige Modifikationen (bspw. LabyMod, OptiFine) sind ggf. nicht für die Server-Version ausgelegt oder selbst nicht auf dem aktuellen Stand. Versucht in solch einem Fall, euch einmal mit einer Installation ohne Modifikationen zu verbinden.

### Firewall-Einstellungen

Minecraft verwendet für die Verbindung den Port `25565` über TCP und UDP. Die Bedrock-Version verwendet zum Verbinden die Ports `19132` und `19134`.

Bitte prüfe in deiner Firewall, deinem Router und ggf. deiner Sicherheitssoftware, dass diese Ports **nicht** blockiert werden. Wie du das am besten machst, erfährst du durch eine Recherche auf Google.
