# ...schlägt fehl

### Unterstützte Versionen

Wir unterstützen das Verbinden mit Minecraft-Clients in den Versionen **ab 1.21.4** – Wir empfehlen zum fehlerfreien Spielen die Version **aktuelle Version des Cloud-Netzwerkes** zu verwenden.

{% hint style="info" %}
Die aktuelle Version des Cloud-Netzwerkes ist die 1.21.4.
{% endhint %}

\
Die Minecraft-Menü im Launcher der Java-Edition kann wie folgt geändert werden:<br>

* Minecraft Launcher starten
* Auswahl "Installationen"
* Auswahl "Neu"
* Name vergeben
* Spielversion auswählen (siehe oben)
* Button "Speichern" drücken
* Auswahl "Spielen"
* Dropdown-Box in der unteren linken Ecke auswählen und das ausgewählte Profil anklicken
* Button "Spielen"

Neue Spielversionen werden von uns schnellstmöglich nach Release durch Microsoft freigegeben. Dies kann unter Umständen einige Stunden bis Tage dauern. Den aktuellen Stand zu Updates erfahrt ihr auf unserem [Discord-Server](https://discord.gg/abge).

{% hint style="warning" %}
Beta-Versionen der Bedrock Edition und Entwicklungs-Versionen der Java Edition werden von uns **nicht** unterstützt.&#x20;
{% endhint %}

### Serververbindung schlägt fehl

Sollte eine Verbindung über die Hauptadressen nicht möglich sein, kann im Einzelfall die Nutzung der alternativen Adresse: `alt.griefergames.net` sinnvoll sein.&#x20;

### Zu viele Verbindungen

Spielen viele Leute gleichzeitig bei euch über ein Netzwerk _(z.B. Familie, Schule, Wohnheim, etc.)_?\
Aus Sicherheitsgründen limitieren wir die Anzahl an Verbindungen pro IP-Adresse. Betroffene Nutzer können mit einem VPN einen anderen Access-Server auswählen.&#x20;

### Modifikationen

Einige Modifikationen (bspw. LabyMod, OptFine, etc.) sind ggf. nicht für die Server-Version ausgelegt oder selbst nicht auf aktuellem Stand. Versucht in solch einem Fall einmal mit einer Installation ohne Modifikation zu verbinden.

### Firewall-Einstellungen

Minecraft verwendet für die Verbindung den Port `25565` über TCP und UDP. Die Bedrock-Version verwendet zum Verbinden den Port `19132` und `19134`. \
Bitte prüfe in deiner Firewall, deinem Router und ggf. deiner Sicherheitssoftware, dass diese Ports **nicht** blockiert werden. Wie du das am besten machst, erfährst du durch eine Recherche auf Google.
