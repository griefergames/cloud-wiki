# 🔗 Server verbinden...

{% hint style="info" %}
Serveradresse: <mark style="color:orange;">**griefergames.net**</mark>
{% endhint %}

GrieferGames kannst du sowohl mit der [Java-Edition](mit-der-java-edition.md) als auch mit der [Bedrock-Edition](mit-der-bedrock-edition.md) betreten.

Der Server basiert auf der Java-Version und bietet daher in der Java-Edition das bessere Spielerlebnis. Wir arbeiten jedoch dauerhaft daran, dass auch in der Bedrock-Edition ein gutes Spielerlebnis geboten wird.
