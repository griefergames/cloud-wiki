# 🏷️ Chat-Tags

Ihr wollt anderen Spielern schnell euer Inventar zeigen, eure Rüstung präsentieren oder jemanden direkt auf euer Profil aufmerksam machen?

Dann ist das neuen Chat-Tag System auf der Cloud perfekt für euch!

Hier alle verfügbaren Chat-Tags inklusive Beschreibung:

### Nutzbar für alle:
* **`%inv%`**\
   Zeigt eure Inventar
* **`%ec%`**\
   Zeigt eure Endertruhe
* **`%armor%`**\
   Zeigt eure aktuell getragene Rüstung
* **`%profil%`**\
   Verlinkt euer Profil
* **`%item%`**\
   Verlinkt ein Item in eurer Hand 
   
### Einlösbares Rechte:

* **`%plot%`**\
   Teilt eines eurer Grundstück (auf dem ihr steht)
* **`%here%`**\
   Andere Spieler können sich darüber direkt zum Standort teleportieren!

{% hint style="info" %}
Bei allen Tags(außer`%here%`) ist es möglich zusätzlich andere Spieler zu verlinken. 
-> `%inv:nutzername%` bzw. `%plot:alias/nutzername%`
{% endhint %}
