# Upgradebare Tools

<figure><img src="../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

Upgradebare Tools verbessern sich durch die Nutzung des Tools. Die Upgrades beziehen sich dabei auf einzelne Blöcke oder Blockarten.&#x20;

{% hint style="info" %}
Einige Blöcke sind dabei zusammengefasst. z.B. zählen alle Erze eines Typs (z.B. Redstoneerz & Tiefenschiefer-Redstoneerz) zusammen.
{% endhint %}

Auf dem Item sind die bereits abgebauten Blöcke mit deren Fortschritt hinterlegt. Also z.B. in diesem Beispiel Erde mit einem Fortschritt von 1/777 auf Level 0. Es müssen somit noch 776 Erd-Blöcke abgebaut werden, damit sich das Level von Erde auf 1 erhöht.

Jedes Level steht dabei für eine Effizienz-Stufe. In diesem Fall ist das maximale Block-Level auf Stufe 7 festgelegt. Das bedeutet, dass jeder Block maximal auf Stufe 7 aufgelevelt werden kann und damit für diesen Block Effizienz 7 erhält.

## Blöcke hinzufügen

Durch das Abbauen eines neuen Blocks wird dieser Block automatisch auf das Tool auf Level 0 hinzugefügt.&#x20;

{% hint style="info" %}
Auf ein Tool kann nur eine bestimmte Anzahl an Blöcken oder Blockgruppen hinzugefügt werden. Standardmäßig sind diese auf 7 begrenzt.
{% endhint %}

## Blöcke leveln

Mit jedem Block der abgebaut wird, steigt der Fortschritt dieses Blocks. Ist der Fortschritt auf 100% erhöht sich das Blocklevel um 1. Damit ist die Effizienz beim Abbau dieser Blockgruppe dann ebenfalls um 1 erhöht.

Dieses wiederholt sich so lange, bis die maximale Blockstufe erreicht ist.

{% hint style="success" %}
Jedes Mal, wenn sich ein Block-Level erhöht wird das Tool repariert (dabei wird kein "Ambosslevel" verbraucht).
{% endhint %}

## Haltbarkeit

Auch die Haltbarkeit auf den Tools levelt sich mit. Diese orientiert sich meist an der Blockanzahl der Blöcke. Diese erhöht sich bei jedem Blockabbau eines Blockes, welcher auf dem Tool hinterlegt ist.

Auch hier steigt mit jeder Stufe das Level der Haltbarkeitsverzauberung.

{% hint style="success" %}
Wird eine neue Haltbarkeitsstufe erreicht, wird das Tool ebenfalls repariert und gleichzeitig das Ambosslevel wieder zurückgesetzt.
{% endhint %}
