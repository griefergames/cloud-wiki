# Schneeballschlacht

Für eine Schneeballschlacht-Map benötigst du mehrere Spawn-Punkte, einen Pre-Spawn-Punkt und Schneeplatten, an denen die Spieler neue Schneebälle erhalten.

## Spawn-Punkte

Es werden **mehrere** [Spawn-Punkte](./#spender-dropper) benötigt, die in der Runde zufällig für den Spawn und Respawn genutzt werden. Zusätzlich wird ein [Pre-Spawn-Punkt](./#werfer-dispenser) benötigt.

## Schneeplatten

Damit die Spieler im Spiel an weitere Schneebälle kommen, werden auf der Karte Schneeplatten (Schneeteppiche) benötigt. Diese können in verschiedenen Höhen platziert werden, dürfen jedoch keinen vollen Block ergeben (8 Schichten).
