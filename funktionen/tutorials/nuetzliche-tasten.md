# ⌨️ Nützliche Tasten & Anzeigen

Viele nützliche Infos zeigt Minecraft nur auf Tastendruck: deine Koordinaten, die Chunk-Grenzen oder die genaue Haltbarkeit eines Werkzeugs. Hier findest du die wichtigsten Tasten der Java Edition und was du auf GrieferGames zusätzlich nutzen kannst.

{% hint style="info" %}
Auf vielen Laptops und Macs musst du für die Tasten **F1 bis F12** zusätzlich die **Fn**-Taste gedrückt halten.
{% endhint %}

## Der Debug-Bildschirm (F3)

Mit F3 blendest du den Debug-Bildschirm ein und wieder aus. Links stehen unter anderem deine genaue Position unter **XYZ**, wobei die Y-Koordinate deine Höhe angibt, X nach Osten größer wird und Z nach Süden. In der Zeile **Chunk** siehst du deine Position innerhalb des aktuellen Chunks (0 bis 15) und die Koordinaten des Chunks selbst. **Facing** zeigt dir deine Blickrichtung als Himmelsrichtung zusammen mit der Achse, auf die du schaust. Außerdem siehst du dort das **Biom** und das **Lichtlevel** an deiner aktuellen Position. Rechts auf dem Bildschirm siehst du zudem den Namen und den Zustand des Blocks, auf den dein Fadenkreuz gerade zeigt.

## Tastenkombinationen mit F3

Halte F3 gedrückt und drück dann die zweite Taste:

| Kombination | Was passiert |
| :--- | :--- |
| **F3 + G** | Zeigt die Chunk-Grenzen als Linien an. |
| **F3 + H** | **Erweiterte Schnellinfo:** Im Inventar stehen der ID-Name eines Gegenstands und bei beschädigten Werkzeugen und Rüstungen die genaue Haltbarkeit. |
| **F3 + B** | Zeigt die Hitboxen von Kreaturen, Spielern und herumliegenden Items, mit Blickrichtung. |
| **F3 + A** | Lädt alle Chunks neu, z. B. wenn ein Loch in der Welt angezeigt wird. |
| **F3 + T** | Lädt Ressourcenpakete mit Texturen und Sounds neu. |
| **F3 + D** | Leert den Chat. |

{% hint style="info" %}
Die Haltbarkeit siehst du auch ohne **F3 + H** am Balken unter dem Gegenstand. Er wird mit der Zeit kürzer und wechselt von Grün über Gelb zu Rot. Der Balken erscheint, sobald du einen Gegenstand benutzt hast.
{% endhint %}

## Weitere Tasten

| Taste | Was passiert |
| :--- | :--- |
| **F1** | Blendet alle Anzeigen aus, praktisch für Screenshots. |
| **F2** | Macht einen Screenshot. Er landet im Ordner `screenshots` in deinem `.minecraft`-Ordner. |
| **F5** | Wechselt die Ansicht: aus deinen Augen, von hinten und von vorne. |
| **F11** | Vollbild an und aus. |
| **Tab** *(gedrückt halten)* | Zeigt alle Spieler auf dem Server. |
| **L** | Öffnet die Erfolge. Auf der Cloud findest du dort eigene Erfolge von GrieferGames. |
| **Mittelklick** | Schaust du einen Block an, den du dabeihast, nimmst du ihn damit in die Hand. |
| **Shift + Klick** | Verschiebt einen Stapel zwischen Truhe und Inventar. |
| **Shift + Doppelklick** | Nimm einen beliebigen Gegenstand auf die Maus, halte Shift und doppelklicke auf eine Sorte. Dann wandern alle Stapel dieser Sorte auf einmal hinüber. |

## Sichtweite und Simulationsweite

Hinter deiner Sichtweite beginnt der Nebel. Wie weit du siehst, begrenzt auch der Server. Beides stellst du unter *Optionen → Grafikeinstellungen* ein. Ein Chunk ist 16 × 16 Blöcke groß und reicht über die ganze Höhe der Welt.

- **Sichtweite:** Legt fest, wie viele Chunks in jede Richtung du siehst, von 2 bis 32. Je mehr, desto mehr Leistung braucht dein Rechner. Ruckelt das Spiel, hilft eine kleinere Sichtweite.
- **Simulationsweite:** Bestimmt, in wie vielen Chunks Kreaturen bewegt und Blöcke aktualisiert werden, von 5 bis 32.

Auf einem Server legt der Server fest, wie weit er dir die Welt höchstens schickt. Stellst du eine größere Sichtweite ein, siehst du trotzdem nicht weiter.

{% hint style="success" %}
Bleibt deine Bildrate an einem festen Wert hängen, z. B. bei 60, schau in den Grafikeinstellungen bei **Max. Bildrate** und **VSync** nach. VSync passt die Bildrate an deinen Monitor an.
{% endhint %}

## Bedrock Edition

Den Debug-Bildschirm und alle Kombinationen mit F3 gibt es nur in der Java Edition. In der Bedrock Edition stellst du die Sichtweite in den Video-Einstellungen ein, dort heißt sie *Renderdistanz*. Auch hier begrenzt der Server, wie weit du siehst. 

GrieferGames läuft auf der Java-Version und bietet deshalb in der Java Edition das bessere Spielerlebnis. Mehr dazu unter **[Mit der Bedrock-Edition joinen](https://wiki.griefergames.net/cloud/auf-den-server-joinen/mit-der-bedrock-edition)**.
