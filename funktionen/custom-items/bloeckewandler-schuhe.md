# Blöckewandler-Schuhe

Die **Blöckewandler-Schuhe** verwandeln die Blöcke unter deinen Füßen, während du läufst. So legst du in der Farmwelt im Vorbeigehen Trampelpfade oder Ackerboden an.

## Editionen

| Edition | Wirkt auf | Wird zu |
| ------- | --------- | ------- |
| Trampelpfad | Grasblock, Erde, Grobe Erde, Podsol, Myzel | Trampelpfad |
| Ackerboden | Grasblock, Erde, Grobe Erde | Ackerboden |

Welche Edition du hast, steht auf den Schuhen.

## So funktioniert das Item

1. Ziehe die Blöckewandler-Schuhe an.
2. Laufe in der Farmwelt über passende Blöcke.
3. Jeder Block, über den du läufst, wird verwandelt.
