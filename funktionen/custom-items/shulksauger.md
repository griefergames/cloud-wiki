# Shulksauger

Der **Shulksauger** ist eine Shulker-Kiste, die ausgewählte Materialien beim Aufsammeln automatisch in sich aufnimmt. So bleibt dein Inventar beim Farmen länger frei.

## Materialien einstellen

Um die Materialien des Shulksaugers zu bearbeiten, nimmt man ihn in die Hand und gibt `/shulkercollector` ein. Dadurch öffnet sich das Menü **„Shulker-Sammler bearbeiten“**.

Dort kann man im eigenen Inventar auf ein Item klicken, um das entsprechende Material hinzuzufügen. Bereits hinzugefügte Materialien lassen sich durch einen Klick auf das jeweilige Item im Menü wieder entfernen.

{% hint style="info" %}
Wie viele Materialien du einstellen kannst, steht auf dem Shulksauger. Die Materialien kannst du jederzeit ändern.
{% endhint %}

## So funktioniert das Item

Hast du den Shulksauger im Inventar, landen aufgesammelte Items der eingestellten Materialien direkt in der Shulker-Kiste. Passt nicht alles hinein, kommt der Rest wie gewohnt in dein Inventar.

{% hint style="warning" %}
Der Shulksauger sammelt nur, solange in deinem Inventar noch Platz für die Items wäre. Ist dein Inventar komplett voll, bleiben die Items liegen.
{% endhint %}

{% hint style="success" %}
Platzierst du den Shulksauger und baust ihn wieder ab, bleiben seine eingestellten Materialien erhalten.
{% endhint %}
