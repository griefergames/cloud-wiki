# Geladener Blitzableiter

Mit dem **Geladenen Blitzableiter** rufst du einen Blitz herbei, ohne auf ein Gewitter warten zu müssen. So kannst du z. B. geladene Creeper erzeugen.

## So funktioniert das Item

1. Platziere den Geladenen Blitzableiter.
2. Direkt danach schlägt ein Blitz genau an dieser Stelle ein.

{% hint style="info" %}
Die Ladung wirkt nur einmal. Danach ist der platzierte Block ein gewöhnlicher Blitzableiter.
{% endhint %}

{% hint style="warning" %}
Der Blitz kann Nebeneffekte haben. Bei manchen Blitzableitern erscheint mit einer gewissen Chance eine Skelettpferd-Falle.
{% endhint %}
