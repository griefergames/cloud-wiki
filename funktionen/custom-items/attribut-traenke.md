# Attribut-Tränke

**Attribut-Tränke** verändern für eine bestimmte Zeit die Eigenschaften (Attribute) von Spielern und Kreaturen. Dazu gehören z. B. der **Trank der Ameise**, der **Trank der Schildkröte** und der **Trank des Riesen**.

Welche Eigenschaften sich ändern und wie lange die Wirkung anhält, steht auf dem Trank.

## So funktioniert das Item

Attribut-Tränke gibt es als Trank, Wurftrank und Verweiltrank:

* **Trank:** Trinkst du ihn, wirkt er auf dich.
* **Wurftrank:** Er wirkt auf alle Spieler und Kreaturen, die er beim Aufprall trifft.
* **Verweiltrank:** Er hinterlässt nach dem Wurf eine Wolke. Wer hineingerät, erhält die Wirkung.

{% hint style="warning" %}
Die Wirkung endet, sobald du die Region wechselst oder den Server verlässt.
{% endhint %}
