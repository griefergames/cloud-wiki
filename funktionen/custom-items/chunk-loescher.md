# Chunk-Löscher

Mit dem **Chunk-Löscher** höhlst du den Untergrund deines Grundstücks in kürzester Zeit aus. Ein einziger Abbau entfernt die grobe Erde im ganzen Chunk.

## Stufen

Den Chunk-Löscher gibt es in fünf Stufen, die sich in der Anzahl der Nutzungen unterscheiden.

| Item | Nutzungen |
| ---- | --------- |
| Chunk-Löscher | 30 |
| Großer Chunk-Löscher | 60 |
| Mega Chunk-Löscher | 90 |
| Giga Chunk-Löscher | 200 |
| Ultra Chunk-Löscher | 500 |

## So funktioniert das Item

1. Stelle dich auf dein Grundstück.
2. Baue mit dem Chunk-Löscher einen Block grobe Erde ab.
3. Die gesamte grobe Erde in diesem Chunk wird bis zur Höhe 64 entfernt, soweit sie auf deinem Grundstück liegt.
4. Jede Nutzung verbraucht 1 Haltbarkeit. Die verbleibenden Nutzungen stehen auf dem Item.

{% hint style="info" %}
Damit du beim Aushöhlen nicht in die Tiefe stürzt, bekommst du für **30 Sekunden** den Effekt Sanfter Fall. Mit einem Rechtsklick mit dem Chunk-Löscher entfernst du den Effekt wieder.
{% endhint %}

{% hint style="warning" %}
* Der Chunk-Löscher funktioniert nur auf dem Citybuild und nur auf Grundstücken, deren Besitzer du bist.
* Er wirkt ausschließlich auf grober Erde. Die entfernte Erde bekommst du nicht als Item.
{% endhint %}
