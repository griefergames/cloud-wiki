# Betonmischer

Mit dem **Betonmischer** stellst du Beton und Trockenbeton in großen Mengen her. Mit einem Wassereimer bekommst du direkt fertigen Beton und musst das Pulver nicht erst im Wasser aushärten lassen.

Der Betonmischer wird wie ein Block platziert und sieht aus wie ein Kessel. Du kannst ihn wieder abbauen und woanders aufstellen.

## So funktioniert das Item

1. Rechtsklicke mit leerer Hand auf den Betonmischer. Das Menü „Betonmischer“ öffnet sich.
2. Klicke in deinem Inventar auf Sand, Kies und einen Farbstoff, um sie in den Mischer zu legen.
3. Klicke auf einen Wassereimer, wenn du direkt fertigen Beton haben möchtest.
4. Klicke auf „Jetzt mischen“.

Übrige Zutaten bekommst du nach dem Mischen zurück.

{% hint style="info" %}
Mit einem Shift-Klick auf „Jetzt mischen“ nutzt der Mischer sofort alle passenden Zutaten aus deinem Inventar. Liegt dabei ein normaler Wassereimer in deinem Inventar, entsteht direkt Beton.
{% endhint %}

## Rezept

| Zutaten | Ergebnis |
| ------- | -------- |
| 4 Sand, 4 Kies, 1 Farbstoff | 8 Trockenbeton |
| 4 Sand, 4 Kies, 1 Farbstoff und ein Wassereimer | 8 Beton |

Der Farbstoff bestimmt die Farbe. Pro Mischvorgang kannst du nur eine Farbe verwenden.

{% hint style="success" %}
Ein einziger Wassereimer reicht für einen vollen Betonmisch-Vorgang. Den leeren Eimer bekommst du zurück.
{% endhint %}

{% hint style="warning" %}
* Es funktionieren nur normale Wassereimer. Unendliche oder andere besondere Eimer kannst du im Betonmischer nicht verwenden.
* Auf einem Grundstück kann den Betonmischer nur benutzen, wer dort Besitzer oder hinzugefügt ist.
{% endhint %}
