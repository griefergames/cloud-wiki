# Köpfe-Vergrößerer

Mit dem Köpfe-Vergrößerer kannst du platzierte Spieler- und Deko-Köpfe auf Blockgröße anwachsen lassen, perfekt für Dekorationen oder besondere Effekte. Das Item kann man 10-mal benutzen, bevor es kaputtgeht.

<p align="center"><img src="../../.gitbook/assets/unknown (7) (1) (1) (1).png" alt=""></p>

{% hint style="info" %}
Dieses Item hat eine [Limitierte Gegenstandsnutzung](../features/limtierte-gegenstandsnutzung.md).
{% endhint %}

## So funktioniert das Item

1. Platziere den Kopf, den du vergrößern möchtest. Das geht auf dem Boden und an einer Wand.
2. Halte den Köpfe-Vergrößerer in der Hand.
3. Rechtsklicke auf den platzierten Kopf mit dem Köpfe-Vergrößerer, um ihn zu vergrößern.

{% hint style="info" %}
Der vergrößerte Kopf schaut in dieselbe Richtung wie der platzierte Kopf. Richte den Kopf also vorher so aus, wie er später aussehen soll.
{% endhint %}

{% hint style="warning" %}
* Wird der Kopf wieder abgebaut, verschwindet die Vergrößerung automatisch.
* Mob-Köpfe wie Creeper-, Zombie- oder Drachenköpfe lassen sich nicht vergrößern.
{% endhint %}
