# Köpfe-Vergrößerer

Mit dem Köpfe-Vergrößerer kannst du jeden platzierten Kopf auf Blockgröße anwachsen lassen, perfekt für Dekorationen oder besondere Effekte. Das Item kann man 10 mal benutzen, bevor es kaputt geht.

<p align="center"><img src="../../.gitbook/assets/unknown (7) (1).png" alt=""></p>

{% hint style="info" %}
Dieses Item hat eine [Limitierte Gegenstandsnutzung](../features/limtierte-gegenstandsnutzung.md).
{% endhint %}

## So funktioniert das Item

1. Platziere den Kopf, den du vergrößern möchtest.
2. Halte den Köpfe-Vergrößerer in der Hand.
3. Rechtsklicke auf den platzierten Kopf mit dem Köpfe-Vergrößerer, um ihn zu vergrößern.

{% hint style="warning" %}
Wird der Kopf wieder abgebaut, verschwindet die Vergrößerung automatisch.
{% endhint %}
