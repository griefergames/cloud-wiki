# Köpfe-Säbel

Der Köpfe-Säbel hat standardmäßig 150 Nutzungen. Mit ihm kannst du gezielt den Kopf eines Spielers erhalten, den du mit Linksklick schlägst.&#x20;

{% hint style="info" %}
Auf einem Plot muss die PVP-Flag aktiviert sein.
{% endhint %}

<p align="center"><img src="../../.gitbook/assets/unknown (6).png" alt=""></p>

## So funktioniert das Item

1. Stelle sicher, dass auf dem Plot die PVP-Flag auf true gesetzt ist.
2. Linksklick auf den Spieler, von dem du den Kopf haben möchtest, während du den Säbel in der Hand hältst.
3. Der Kopf landet automatisch in deinem Inventar.
4. Jeder Treffer verringert die Haltbarkeit des Säbels um 1.

{% hint style="info" %}
Dieses Item hat eine [Limitierte Gegenstandsnutzung](../features/limtierte-gegenstandsnutzung.md).
{% endhint %}
