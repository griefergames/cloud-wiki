# Überraschungs-Spawn-Ei

Das **Überraschungs-Spawn-Ei** verrät erst beim Benutzen, welche Kreatur darin steckt. Setzt du es in einen Spawner ein, entscheidet der Zufall, welche Kreatur der Spawner ab dann erzeugt.

## Varianten

* **Feindlich:** Der Spawner erzeugt ein zufälliges feindliches Monster. Auch Schleime, Magmawürfel, Hoglins sowie Skelett- und Zombiepferde sind möglich.
* **Friedlich:** Der Spawner erzeugt ein zufälliges friedliches Tier. Auch ein Eisengolem ist möglich.

Welche Variante du hast, steht auf dem Ei.

## So funktioniert das Item

Um ein **Überraschungs-Spawn-Ei** zu verwenden, benötigt man einen Spawner in der [Farmwelt](https://wiki.griefergames.net/cloud/funktionen/spielmodus-citybuild/die-farmwelten). Alternativ kann man einen **Farmwelt-Spawner** aufstellen.

Anschließend klickt man mit dem Überraschungs-Spawn-Ei per Rechtsklick auf den Spawner. Das Ei wird dabei verbraucht und der Spawner erzeugt ab sofort die zufällig ausgewählte Kreatur.

{% hint style="warning" %}
Das Überraschungs-Spawn-Ei lässt sich nur in der Farmwelt auf Spawner anwenden.
{% endhint %}

{% hint style="danger" %}
Die [Farmwelten](../spielmodus-citybuild/die-farmwelten.md) werden **jeden Monat** zurückgesetzt. Dabei verschwinden auch dein Farmwelt-Spawner und jeder Spawner, in den du ein Überraschungs-Spawn-Ei eingesetzt hast.
{% endhint %}
