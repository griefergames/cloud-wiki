# 🦾 Mechanik-Änderungen

## Trichter-Geschwindigkeiten

Die Trichter-Ticks / -Geschwindigkeiten sind auf GrieferGames angepasst. Mehr dazu ist in unserer umfassenden Änderung des [Trichter-Systems](../features/tricher-system.md) zu finden.&#x20;

## Shulker-Änderungen

### Drop-Rate

Die Drop-Rate der Schulker-Schalen ist reduziert gegenüber der Standardwahrscheinlichkeit.

{% hint style="success" %}
_Die Droprate wurde in **Absprache mit der Community** zur Einführung der Shulker-Kisten geändert. GrieferGames hat auf Wunsch der Community Shulker-Kisten über normales Farmen verfügbar gemacht, statt durch in Kisten / Events oder Custom Rezepte herauszugeben._
{% endhint %}

### Shulker-Farmen

Die Shulker-Farmen, welche man auf YT o.ä. findet, funktionieren auf GrieferGames nicht. Der Bau der Farm funktioniert, jedoch wird man beim Betrieb schnell feststellen, dass keine neuen Shulker dazu kommen.

### Inhalte von Shulker-Kisten

Minecraft selbst verbietet nur den Inhalt von Shulker-Kisten in Shulker-Kisten. Wir haben diese Beschränkung jedoch erweitert. Es können ebenfalls keine Bücher in Shulker-Kisten abgelegt werden.

{% hint style="warning" %}
Es gibt Möglichkeiten Bücher in eine Shulker-Kiste zu bekommen, ihr bekommt diese jedoch nicht wieder aus der Shulker-Kiste heraus. Das Team wird dort nicht helfen.
{% endhint %}

## Pigman-Farmen auf Citybuild-Regionen

Das Farmen von Pigman über die Nether-Portale ist auf der Cloud grundsätzlich möglich. Aufgrund der zu hohen Anzahl der Farmen, wurde hier am 24. April 2023 eine Änderung implementiert.

Weitere Informationen zur Pigman-Farm gibt es auf der Unterseite [Pigman-Farmen](pigman-farmen.md).
