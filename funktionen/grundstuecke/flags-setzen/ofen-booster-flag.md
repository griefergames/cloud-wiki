# Ofen-Booster Flag

Mit dem **Ofen-Booster** Item kannst du auf deinem Plot die **Öfen schneller brennen** lassen, sodass Items sofort gebrannt werden.

<p align="center"><img src="../../../.gitbook/assets/unknown (6).png" alt=""></p>

## Einlösen des Items

1. Stelle sicher, dass du dich auf dem Grundstück befindest, auf dem die Ofen-Booster Flag aktiviert werden soll.
2. Halte das Ofen-Booster Item in der Hand.
3. Rechtsklicke auf dem Plot, um das Item einzulösen.
4. Nach der Einlösung verschwindet das Item aus deinem Inventar.

## Nutzung der Flag auf deinem Grundstück

Durch Einlösen des Ofen-Booster Items wird die fast-burn Flag automatisch aktiviert.

Mit `/p flag set fast-burn false` deaktivierst du sie wieder.

{% hint style="danger" %}
Sobald die fast-burn flag auf false gesetzt wurde, muss ein neuer Ofen-Booster Item eingelöst werden, um die flag wieder einzuschalten.
{% endhint %}
