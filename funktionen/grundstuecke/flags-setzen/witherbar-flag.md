# Witherbar Flag

Mit der **Witherbar-Entfernen-Flag** blendest du auf deinem Grundstück die **Bossbars von Mobs wie dem Wither** aus. Die Leiste mit Name und Lebensanzeige des Mobs erscheint dann nicht mehr am oberen Bildschirmrand.

Die Flag bleibt auf deinem Grundstück aktiv. Sie wirkt nur auf Mobs, die nach dem Aktivieren dort erscheinen.

{% hint style="warning" %}
Nur der **Besitzer** des Grundstücks kann das Item einlösen. Als [Helfer oder Vertrauter](../grundstucksrechte.md) auf einem fremden Grundstück funktioniert es nicht.
{% endhint %}

{% hint style="danger" %}
Wird die Flag deaktiviert oder entfernt, muss eine neue Witherbar-Entfernen-Flag eingelöst werden, um sie wieder einzuschalten.
{% endhint %}
