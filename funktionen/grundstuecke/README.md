# 🏡 Grundstücke

Auf GrieferGames kann jeder Spieler eigene Grundstücke besitzen.

## Grundbefehle

Die allgemeinen Grundstücksbefehle starten mit `/p`. Zusätzlich gibt es noch einige individuelle Befehle und Features.

## 1.16 Grundstücke

Mit der Cloud-Version 1.19 sind neue Grundstückstiefen durch Minecraft hinzugekommen. Diese sind ebenfalls in den Citybuild-Regionen verfügbar. Wenn man noch ein altes Grundstück aus der 1.16 Version besitzt, bei der sich die Bedrockschicht auf der Höhe 0 befindet, kann man sein Grundstück mit dem Befehl `/heightfix` auf die neue Tiefe anpassen.

{% hint style="info" %}
Der untere Teil des Grundstücks wird bei diesem Vorgang nicht mit Erde aufgefüllt und der Bedrock durch Glas ersetzt, damit man beim Schaufeln der Erde nicht 64 Blöcke in die Tiefe stürzt.
{% endhint %}
