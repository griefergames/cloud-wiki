# 🏡 Grundstücke

Auf GrieferGames kann jeder Spieler eigene Grundstücke besitzen.

## Grundbefehle

Die allgemeinen Grundstücksbefehle starten mit `/p`. Zusätzlich gibt es noch einige individuelle Befehle und Features.

Weitere Grundstücke kosten 10.000$</em></td></tr><tr><td>/p h</td><td>Teleportiert dich zu deinem Grundstück.<br>Mit <code>/p h </code><mark style="color:yellow;"><code>Nummer</code></mark> kommst du zum X. deiner Grundstücke.</td></tr><tr><td>/p h <mark style="color:orange;">Spielername</mark></td><td>Teleportiert dich zum Grundstück des Spielers.<br>Mit <code>/p h </code><mark style="color:orange;"><code>Spielername</code></mark> <mark style="color:yellow;"><code>Nummer</code></mark> kommst du zum X. Grundstück des Spielers.</td></tr><tr><td>/p alias set <mark style="color:purple;">Aliasname</mark></td><td>Legt ein Alias für dein Grundstück fest.
