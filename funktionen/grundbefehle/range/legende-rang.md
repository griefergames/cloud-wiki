# Legende-Rang

Der <mark style="color:red;">Legende</mark>-Rang kann nur im Shop gekauft werden. Er ist dauerhaft und enthält natürlich alle Rechte von [Premium ](premium-rang.md)und [Ultra](ultra-rang.md). Zusätzlich bekommst du weitere exklusive Features, die dich und dein Grundstück besonders hervorheben.

## Vorteile

* Hellroter Prefix im Chat
* 5 Homes setzen mit `/sethome`
* [Clan ](../../features/clan-system.md)darf +4 Mitglieder mehr haben
* Musik auf dem Grundstück abspielen lassen mit `/p flag set music`
* Benachrichtigung erhalten, wenn jemand dein Grundstück betritt mit `/p flag set notify-enter true`
* Benachrichtigung erhalten, wenn jemand dein Grundstück verlässt mit `/p flag set notify-leave true`
* Individuelle Grußnachricht senden, wenn jemand dein Grundstück betritt mit `/p flag set greeting`
