## Perks & Rechte

| Befehl                      | Funktion                                                                                                                                                                         |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| /startkick \<NAME> \<GRUND> | Starte eine Startkick-Abstimmung. Die Spieler auf dem Citybuild können nun mit `/ja` und `/nein` abstimmen, ob der besagte User für 15 Minuten vom Server gekickt werden soll.   |
| /startjail \<NAME> \<GRUND> | Starte eine Startjail-Abstimmung. Die Spieler auf dem Citybuild können nun mit `/ja` und `/nein` abstimmen, ob der besagte Spieler 12 Obsidian-Blöcke im Gefängnis abbauen muss. |

Damit ein Spieler bestraft wird, müssen mindestens **zwei Spieler** abstimmen und mindestens **zwei Drittel** mit `/ja` stimmen. Verlässt der betroffene Spieler während der Abstimmung den Server, wird er trotzdem bestraft. Wird ein Spieler wiederholt per StartKick vom Server geworfen, verlängert sich die Dauer.Bevor eine Abstimmung startet, bestätigst du sie in einem Menü. Eine Abstimmung kostet **2.000 Dollar**, bei Erfolg erhältst du die Hälfte zurück.

{% hint style="warning" %}
**Stimmen mehr als zwei Drittel mit **`/nein`**, wirst du selbst bestraft.**
{% endhint %}
