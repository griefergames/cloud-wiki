# Grundstücks-Information

Mit `/p i` bzw. `/plot info` erhältst du eine Übersicht über das Grundstück, auf dem du dich befindest. Die folgende Tabelle erklärt die einzelnen Angaben.

<table><thead><tr><th width="132" align="center">Funktion</th><th>Beschreibung</th></tr></thead><tbody><tr><td align="center">Server</td><td>Zeigt an, auf welchem Unterserver sich das Grundstück befindet.</td></tr><tr><td align="center">ID</td><td>Die ID des Grundstücks, auf welchem man sich befindet, ist wie die UUID des Minecraft-Accounts eindeutig. Sie bleibt immer gleich, egal was man macht.</td></tr><tr><td align="center">Alias</td><td>Der „Spitzname“ des Grundstücks, auf welchem man sich befindet. Er wird mit <code>/p alias set &#x3C;Name></code> festgelegt. Anschließend gelangt man mit <code>/p h &#x3C;Alias></code> zu diesem Grundstück.</td></tr><tr><td align="center">Besitzer</td><td>Zeigt den aktuellen Besitzer an.</td></tr><tr><td align="center">Größe</td><td>Zeigt die Grundstücksgröße an.</td></tr><tr><td align="center">Biom</td><td>Zeigt das aktuelle Biom des Grundstücks an. Das Biom kann mit <code>/p biome</code> geändert werden.</td></tr><tr><td align="center">Vertraut</td><td>Hier werden Leute angezeigt, die man mit <code>/p trust</code> hinzugefügt hat. Sie haben immer Baurechte.</td></tr><tr><td align="center">Mitglieder</td><td>Hier werden Leute angezeigt, die man mit <code>/p add</code> hinzugefügt hat. Sie haben erst dann Baurechte auf dem Grundstück, wenn der Grundstücksbesitzer auf dem Citybuild-Server online ist.</td></tr><tr><td align="center">Verboten</td><td>Hier werden Leute angezeigt, die man mit <code>/p deny</code> vom Grundstück ausgeschlossen hat. Sie haben keine Erlaubnis mehr, das Grundstück zu betreten.</td></tr><tr><td align="center">Flags</td><td>Bei dieser Option werden alle hinzugefügten Flags auf dem Grundstück angezeigt. Mehr Informationen unter <a href="../../grundstuecke/flags-setzen/README.md">Flags setzen</a>.</td></tr></tbody></table>
