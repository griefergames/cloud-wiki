# 🏙️ Spielmodus Citybuild

Citybuild ist ein Spielmodus mit einer zusätzlichen Minecraft-Welt, in welcher jeder Spieler festgelegte Grundstücke (Plots) beanspruchen (claimen) und diese anschließend nach eigenem Wunsch gestalten und bebauen kann.

Zusätzlich zur Plotwelt hast du auf jedem Server eine normale Minecraft-Welt (Farmwelt) und einen Nether.&#x20;

Falls der Platz für ein Bauvorhaben auf einem Grundstück nicht ausreicht, kann man mehrere aneinandergrenzende Grundstücke verbinden (mergen), sofern man diese alle besitzt.

Das Cloud-Netzwerk besteht aus einem großen Citybuild mit vielen kleinen Unterservern. Deine In-Game-Währungen, Items (Inventar & Endertruhe), Chat-Nachrichten und Befehle sind unter allen diesen Unterservern synchronisiert.

{% hint style="info" %}
Es besteht **keine** Synchronisation zwischen dem [1.8-Netzwerk](https://wiki.griefergames.net/) und dem [Cloud-Netzwerk](https://wiki.griefergames.live/). Beide sind komplett voneinander getrennt.&#x20;

Deine 1.8-In-Game-Währungen und Items kannst du **nicht** dorthin mitnehmen.
{% endhint %}
